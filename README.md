## Проекты

### TON NFT Market — Telegram Mini App
Маркетплейс NFT-подарков и аукцион внутри Telegram: кошелёк, торги, витрина, выпуск NFT, настройки профиля.

- Backend на Express: контроллеры аукционов, NFT, авторизации, розыгрышей
- Модели данных и middleware: JWT-авторизация, лимиты запросов, единый обработчик ошибок
- SPA-интерфейс на нативном JS, адаптив под мобильные
- Деплой: Netlify Functions и Vercel

`Node.js` `Express` `REST API` `JavaScript` `Telegram SDK` `TON`

### Telegram Mini App — шаблон и HTTPS-сервер
Готовая база для мини-приложений: Telegram WebApp SDK, темы, MainButton, Popup, локальный HTTPS-сервер с самоподписанными сертификатами для отладки на телефоне.

`JavaScript` `Node.js` `Telegram WebApp` `HTTPS`

### Автоматизация и скрипты
Python-скрипты для рутинных задач: парсинг открытых источников, обработка данных, выгрузка в Excel, интеграция с API.
